# Duplica

Protótipo acadêmico desenvolvido para o TCC da FIAP a partir de um desafio da B3. A Duplica demonstra uma infraestrutura B2B para antecipação e financiamento de duplicatas escriturais, com validação de lastro, marketplace de financiadores e sindicalização automatizada.

## Executar localmente

```bash
npm install
npm run dev
```

O protótipo usa dados fictícios, não possui backend e não representa uma plataforma de negociação de criptoativos.
